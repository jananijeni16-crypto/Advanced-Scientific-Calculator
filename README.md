# Advanced Scientific Calculator

## Project Overview
An advanced scientific calculator developed using Python and Tkinter, featuring mathematical calculations, statistical analysis, unit conversions, CSV data upload, and graphical visualization.

## Features
- Basic Arithmetic Calculator
- Scientific Calculator (DEG/RAD)
- Trigonometric Functions
- CSV File Upload
- Statistical Analysis
- BMI Calculator
- Age Calculator
- Unit Conversions
- Data Visualization using Matplotlib
- Multiple Chart Types (Line, Scatter, Bar, Step, Stem)
- Calculation History

## Tools and Technologies
- Python
- Tkinter
- Matplotlib
- CSV
- Math Library
- Statistics Library
- Visual Studio Code

## Installation

Install the required library:

`pip install -r requirements.txt`

## How to Run / Run the Application 

Run the following command:

`python scientific_calculator.py`

## CSV Visualization

Upload a CSV file, select X-axis and Y-axis columns, choose a chart type, and generate visualizations directly within the application.
