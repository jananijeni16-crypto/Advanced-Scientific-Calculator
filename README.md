# Advanced Scientific Calculator

## Project Overview
The Advanced Scientific Calculator is a Python-based desktop application developed using Tkinter. It combines mathematical calculations and analytical utilities in one graphical interface.

## Features
- Basic Arithmetic Calculator
- Scientific Calculator
- Trigonometric Functions
- DEG and RAD Modes
- Statistical Analysis
- BMI Calculator
- Age Calculator
- Unit Conversions
- Data Visualization using Matplotlib
- Calculation History

## Tools and Technologies
- Python
- Tkinter
- Matplotlib
- Math Library
- Statistics Library
- Visual Studio Code

## Installation

Install the required library:

`pip install -r requirements.txt`

## How to Run

Run the following command:

`python scientific_calculator.py`
